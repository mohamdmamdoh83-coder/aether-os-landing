==================================================
AETHER OS - Futuristic AI Agent Dashboard Template
==================================================

Thank you for your purchase! This template is built with pure HTML, Tailwind CSS (via CDN), and Vanilla JavaScript. It is extremely lightweight and ready to deploy.

--- HOW TO EDIT THE CONTENT ---
1. Open `index.html` in any text editor (VS Code, Notepad, etc.).
2. Use the search function (Ctrl+F or Cmd+F) and look for the comments to find exactly where to replace text, links, and your logo.
3. To change the neon colors (Cyan & Purple), open `style.css` and modify the color variables at the very top of the file.

--- HOW TO DEPLOY FOR FREE (GITHUB PAGES) ---
1. Create a free account on GitHub (github.com).
2. Create a new repository and simply drag-and-drop all these files into it.
3. Go to your repository 'Settings' > 'Pages'.
4. Under 'Source', select the 'main' branch and click Save. 
5. Your futuristic dashboard will be live within 1-2 minutes!
